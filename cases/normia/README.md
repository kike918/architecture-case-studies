# Normia

**Status:** Case candidate — Sprint 0 and technical bootstrap in progress.

## Intended focus

This case will document the architecture of an operational compliance system for food-service environments, grounded in real operational discovery and incremental product development.

Topics expected to be covered:

- task execution and evidence capture;
- deviations, containment and corrective actions;
- supervisor verification;
- auditability and immutable-history principles;
- modular monolith boundaries;
- web-mobile operational UX;
- QR and messaging channels;
- automation boundaries;
- optional external anchoring of audit evidence;
- human + AI-assisted development governance.

## Publication rule

Normia will not be presented as production validated until implementation and pilot evidence support that claim. Current documentation should distinguish architecture baseline, prototype evidence and implemented behavior.
