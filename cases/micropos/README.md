# MicroPOS

**Status:** Case candidate — architecture definition in progress.

## Intended focus

This case will document architecture decisions for a lightweight POS designed for small businesses and low-connectivity environments.

Topics expected to be covered:

- offline-first behavior;
- edge deployment options;
- Raspberry Pi and local-device roles;
- synchronization strategy;
- cost constraints;
- low-connectivity resilience;
- local operation vs. cloud responsibilities;
- maintainability for small teams;
- product packaging beyond software-only delivery.

## Evidence rule

Architecture proposals must be clearly separated from implemented and pilot-validated behavior.
