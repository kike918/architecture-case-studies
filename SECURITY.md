# Security Policy

This repository contains public architecture documentation. Security issues may include accidental disclosure of credentials, sensitive infrastructure details, personal data, confidential client information or implementation details that create material risk.

## Do not open a public issue for sensitive disclosure

When a potential disclosure risk is found, report it privately to the repository owner before discussing details publicly.

## Repository rules

- No credentials, secrets or private keys.
- No production dumps or personal data.
- No private endpoints or sensitive infrastructure maps.
- No confidential client artifacts.
- No proprietary source copied from private repositories.
- Sanitization review is required before publishing case material.

See [`docs/SANITIZATION_GUIDE.md`](docs/SANITIZATION_GUIDE.md).
