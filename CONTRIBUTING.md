# Contributing

## Scope

Contributions should improve architecture clarity, evidence quality, diagrams, trade-off analysis, sanitization or reusable templates.

## Workflow

1. Create an issue or identify the case being improved.
2. Create a focused branch.
3. Update documentation and evidence references.
4. Run sanitization review.
5. Open a Pull Request.
6. Merge only after architecture and public-disclosure review.

## Branch naming

```text
case/<case-name>-<scope>
docs/<scope>
fix/<scope>
```

## Pull Request checklist

- [ ] Purpose is clear.
- [ ] Claims match evidence.
- [ ] No confidential data is exposed.
- [ ] Trade-offs are documented.
- [ ] Diagrams are sanitized.
- [ ] Status/evidence level is explicit.
- [ ] AI-assisted work has been human reviewed.
